Pipeline Architecture & Mathematical Formulation

The pipeline models the logarithmically transformed target variable \( y = \ln(1 + \text{price}) \) to counteract positive skewness and stabilize variance across multiple price tiers.

1. Preprocessing Stage

Continuous attributes are normalized using StandardScaler. Categorical variables are encoded with OneHotEncoder(handle_unknown='ignore') to support unseen production values.

2. Regularized Estimator

Trained using $L_2$-regularized Ridge Regression (\(\alpha = 1.0\)), penalizing collinear one-hot categories while producing stable, interpretable feature attributions.

3. Decision-Support Layer

Back-transforms output using \(\hat{\text{price}} = \exp(\hat{y}) - 1\), computes \(\pm 15\%\) tolerance margins, and categorizes listings into Fair, Overpriced, or Undervalued.
